# المراجعة الآلية للدرجات النهائية

مبادرة تطويرية تقنية مستقلة لمطابقة تقارير رايات وتقني داخل المتصفح.

## النشر على GitHub Pages
1. أنشئي مستودعًا عامًا جديدًا باسم `grade-review`.
2. ارفعي `index.html` و`xlsx-local.js` و`icon.svg` و`.nojekyll` إلى جذر المستودع. لا ترفعي ملفات درجات أو بيانات متدربين.
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. سيكون الرابط `https://USERNAME.github.io/grade-review/` بعد اكتمال النشر.

## مهم قبل التعميم
- التطبيق لا يستخدم خادمًا لمعالجة الدرجات ولا يرفع ملفات الطلاب. راجعي سياسة الخصوصية المؤسسية واختبري الشبكة قبل التعميم.
- دعم XLSX يعتمد على قارئ محلي مبسط، وقد لا يدعم جميع المصنفات أو أنواع الضغط. ملفات XLS القديمة غير مدعومة.
- اختبري الدقة على بيانات وهمية تمثل صيغ تقارير رايات وتقني من عدة كليات، وراجعي الحالات المكررة والناقصة.
- لا ترفعي أي تقارير حقيقية إلى GitHub؛ المستودع العام يعرض جميع ملفاته للآخرين.
- GitHub Pages يستضيف ملفات ثابتة عامة؛ لا تستخدمينه لتخزين بيانات حساسة.
